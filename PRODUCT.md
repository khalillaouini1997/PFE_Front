# Product

## Register

product

## Users
Fleet managers, technicians, and administrative staff who need to monitor client vehicles, track billing, manage server/web accounts, and review access logs. Users work in operational contexts where quick access to real-time data (vehicle locations, account statuses, billing info) is critical.

## Product Purpose
A web administration platform that provides centralized oversight of client fleets, bills, and operational data. It enables account management, real-time vehicle tracking, billing review, and system monitoring for fleet-management service providers.

## Brand Personality
- Functional
- Reliable
- Efficient

## Anti-references
- Avoid cluttered, information-dense dashboards with poor visual hierarchy.
- Avoid generic SaaS "hero metric" templates and over-rounded card-heavy layouts.
- Avoid decorative glassmorphism or gradient text that reduces readability.

## Design Principles
1. **Clarity over decoration**: Every element must serve an operational purpose; remove visual noise.
2. **Efficient wayfinding**: Users should reach any primary task in two clicks or fewer.
3. **Data-first hierarchy**: The most critical information (alerts, KPIs, real-time status) must be immediately visible.
4. **Consistency across modules**: Reuse patterns (tables, forms, cards) so the UI feels like a single system, not a collection of pages.
5. **Respect user time**: Loading states, empty states, and error messages should be helpful and actionable.

## Accessibility & Inclusion
- Target WCAG 2.1 AA compliance.
- Support keyboard navigation and screen-reader-friendly markup.
- Respect `prefers-reduced-motion` for animations.
- Ensure sufficient color contrast for data visualizations and status indicators.
